# Discord Inactivity Kicker Bot 🤖

Discord-бот для автоматического исключения (кика) участников, не проявлявших активность более **30 дней**.

---

## ⚡ Особенности работы

- **Что считается активностью:**
  1. 💬 **Отправка текстового сообщения** в любом текстовом канале сервера (`messageCreate`).
  2. 🎙️ **Подключение или переключение в голосовой канал** (`voiceStateUpdate`).
  - *Больше ничего не продлевает активность* (муты, включение стрима, реакции и т.д. не учитываются).
- **Игнорирование ботов:** Боты полностью исключены из базы и никогда не будут кикнуты.
- **Защита от случайного кика:**
  - Владелец сервера и администраторы защищены от кика.
  - Поддержка иммунных ролей (`IMMUNE_ROLE_IDS`).
  - Защита по иерархии ролей Discord (бот не может кикнуть того, чья роль выше роли бота).
  - Льготный период для новичков: если человек только зашел на сервер и еще ничего не написал, отсчет 30 дней идет от даты вступления (`joinedAt`).
- **Режим тестирования (`DRY_RUN`):** Возможность запустить проверку без реального кика, чтобы оценить список кандидатов.
- **Health Check HTTP Server:** Встроенный веб-сервер на порту `$PORT` для бесплатного хостинга на **Render** и мониторинга через **UptimeRobot**.

---

## 🛠️ Слэш-команды

- `/check-inactivity [dry_run: true/false]` — Ручной запуск проверки участников (доступно только Администраторам).
  - По умолчанию `dry_run = true` (безопасный просмотр без кика).
- `/activity-info [user]` — Показывает статус активности участника: когда зашел, когда последний раз писал/заходил в войс и сколько дней осталось до кика.

## 📋 Шаг 1: Настройка в Discord Developer Portal

1. Перейдите на [Discord Developer Portal](https://discord.com/developers/applications) и нажмите **New Application**.
2. В разделе **Bot**:
   - Нажмите **Reset Token** и скопируйте токен бота (это `DISCORD_TOKEN`).
   - Прокрутите вниз до блока **Privileged Gateway Intents** и **ОБЯЗАТЕЛЬНО ВКЛЮЧИТЕ**:
     - ✅ **Server Members Intent** *(необходим для получения списка участников и их кика)*.
     - *(Guild Messages и Voice States включены по умолчанию)*.
3. В разделе **OAuth2 -> URL Generator**:
   - Отметьте скоупы: `bot`, `applications.commands`.
   - Отметьте права (Bot Permissions):
     - `Kick Members` (Выгонять участников)
     - `View Channels` (Просматривать каналы)
     - `Send Messages` (Отправлять сообщения)
     - `Embed Links` (Встраивать ссылки)
   - Скопируйте полученную ссылку внизу и пригласите бота на свой сервер.
   - **Важно:** В настройках ролей на вашем сервере Discord перетащите роль бота **выше** ролей обычных участников, которых нужно будет кикать (по правилам Discord бот не может кикать тех, чья роль выше его собственной).

## 🚀 Шаг 2: Бесплатный деплой на Render

1. Загрузите код бота в свой репозиторий на **GitHub** (или GitLab).
2. Зарегистрируйтесь на [Render.com](https://render.com).
3. Нажмите кнопку **New +** -> **Web Service**.
4. Подключите ваш GitHub-репозиторий.
5. Заполните параметры сервиса:
   - **Name:** `discord-inactivity-bot`
   - **Language:** `Node`
   - **Branch:** `main` (или `master`)
   - **Build Command:** `npm install && npm run build`
   - **Start Command:** `npm start`
   - **Plan:** `Free`
6. В блоке **Environment Variables** добавьте переменные:
   - `DISCORD_TOKEN` = `ваш_токен_бота`
   - `CLIENT_ID` = `ID_вашего_приложения_из_раздела_General_Information`
   - `INACTIVITY_DAYS` = `30`
   - `CHECK_INTERVAL_HOURS` = `12`
   - `DRY_RUN` = `true` *(рекомендуем на первые пару дней оставить `true`, чтобы проверить работу без кика, затем сменить на `false`)*
   - `LOG_CHANNEL_ID` = *(опционально: ID канала на сервере для логов проверки)*
   - `IMMUNE_ROLE_IDS` = *(опционально: ID ролей с иммунитетом через запятую)*
7. Нажмите **Deploy Web Service**.

### ⏰ Как сделать работу 24/7 бесплатной на Render:
Бесплатные Web Service на Render засыпают через 15 минут, если нет входящих HTTP-запросов.
Поскольку в нашего бота уже встроен HTTP-сервер, вы можете бесплатно поддерживать его бодрствующим:
1. Скопируйте адрес вашего приложения на Render (например, `https://discord-inactivity-bot-xxxx.onrender.com`).
2. Перейдите на бесплатный сервис [UptimeRobot.com](https://uptimerobot.com) или [cron-job.org](https://cron-job.org).
3. Создайте новый монитор:
   - **Type:** HTTP(s)
   - **URL:** `https://ваш-бот.onrender.com/health`
   - **Interval:** каждые 5–10 минут.
4. Теперь сервис будет регулярно пинговать бота, и Render **никогда не усыпит процесс**!

## 💻 Локальный запуск (для разработки/проверки)

Требуется Node.js версии **22+** (или 24+).

1. Клонируйте репозиторий:
   ```bash
   git clone <URL_РЕПОЗИТОРИЯ>
   cd fearless-lavoisier
   ```
2. Установите зависимости:
   ```bash
   npm install
   ```
3. Скопируйте `.env.example` в `.env` и укажите данные:
   ```bash
   cp .env.example .env
   ```
4. Запустите тесты:
   ```bash
   npm test
   ```
5. Запустите бота в режиме разработки:
   ```bash
   npm run dev
   ```
   Или соберите и запустите продакшн-версию:
   ```bash
   npm run build
   npm start
   ```

## 🐳 Запуск через Docker

Если вы предпочитаете запускать бота на VPS или через Docker:
```bash
docker build -t discord-inactivity-bot .
docker run -d \
  --name discord-inactivity-bot \
  --restart unless-stopped \
  -e DISCORD_TOKEN="ваш_токен" \
  -e CLIENT_ID="ваш_client_id" \
  -e DRY_RUN="false" \
  -v $(pwd)/data:/app/data \
  -p 3000:3000 \
  discord-inactivity-bot
```
