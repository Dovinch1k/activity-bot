# 🎬 Video & GIF Downloader (Pinterest + YouTube)

Локальный скрипт на Python для скачивания видео с **Pinterest** и **YouTube** с гибким выбором качества (1080p, 720p, 480p, 360p, max), обрезкой фрагментов и сохранением в формате **GIF**, **MP4 видео со звуком** или обоих одновременно прямо в папку со скриптом.

---

## ✨ Возможности

- **Поддержка платформ:**
  - **YouTube:** обычные видео (`youtube.com/watch?v=...`), короткие ссылки (`youtu.be/...`), Shorts (`youtube.com/shorts/...`)
  - **Pinterest:** обычные пины (`pinterest.com/pin/...`), мобильные ссылки (`pin.it/...`), прямые ссылки на `.mp4`
- **Выбор формата сохранения:**
  - **GIF** (двухпроходная качественная палитра FFmpeg `palettegen` + `paletteuse`, плавные 20 FPS по умолчанию)
  - **MP4 видео со звуком** (чистый звук AAC + видео H.264)
  - **И GIF, и MP4** одновременно
- **Выбор качества:**
  - `1080p` (Full HD)
  - `720p` (HD)
  - `480p` (рекомендуется для GIF — отличный баланс размера и качества)
  - `360p` (компактный размер)
  - `best` (максимальное доступное)
- **Обрезка по времени:**
  - Можно указать конкретный таймкод фрагмента: например, `0:10-0:25` или `15-45`
  - По нажатию `Enter` обрабатывается всё видео целиком
- **Удобство использования:**
  - Интерактивный режим с простыми подсказками (Enter = выбор по умолчанию)
  - Запуск в один клик через `run.bat` на Windows
  - Работа через аргументы командной строки
  - Не требует ручной установки FFmpeg (используется встроенный модуль `imageio-ffmpeg`)

## 🚀 Быстрый старт

### 1. Запуск через `run.bat` (самый простой способ)
Просто дважды кликните по файлу **`run.bat`**.

В открывшемся окне:
1. Вставьте ссылку на видео (Pinterest или YouTube).
2. Выберите формат: `[1] GIF`, `[2] MP4 видео`, `[3] И GIF, и MP4` *(Enter = GIF)*.
3. Выберите качество: `1080p`, `720p`, `480p`, `360p` или `Оригинал` *(Enter = дефолт)*.
4. Укажите отрезок времени *(например `0:10-0:25` или просто Enter для всего видео)*.

Файл сразу сохранится в папку скрипта!

---

### 2. Запуск через консоль

#### Интерактивный режим:
```bash
python pinterest_to_gif.py
```

#### Быстрые команды (CLI):
- **Сделать GIF из YouTube Shorts с обрезкой:**
  ```bash
  python pinterest_to_gif.py "https://youtube.com/shorts/..." --trim "0:02-0:10"
  ```
- **Скачать видео с YouTube в 1080p Full HD:**
  ```bash
  python pinterest_to_gif.py "https://www.youtube.com/watch?v=..." --mode video --quality 1080
  ```
- **Скачать только фрагмент видео со звуком в MP4:**
  ```bash
  python pinterest_to_gif.py "https://www.youtube.com/watch?v=..." --mode video --quality 720 --trim "1:15-1:45"
  ```
- **Сделать GIF в 720p HD:**
  ```bash
  python pinterest_to_gif.py "https://pin.it/..." --quality 720
  ```

## ⚙️ Список аргументов командной строки

| Параметр | По умолчанию | Описание |
|---|---|---|
| `--mode`, `-m` | `gif` | Режим: `gif`, `video` (MP4 со звуком), `both` (и видео, и GIF). |
| `--quality`, `-q` | `480` (для GIF) / `1080` (для video) | Качество: `360`, `480`, `720`, `1080`, `best`. |
| `--trim`, `-t` | `None` (всё видео) | Отрезок времени: `0:10-0:25` или `10-30`. |
| `--fps` | `20` | Частота кадров GIF. |
| `--width` | `480` | Максимальная ширина GIF в px (0 = без сжатия). |
| `--speed` | `1.0` | Скорость анимации (например `1.5` для ускорения). |
| `--output-dir`, `-o` | Папка скрипта | Папка для сохранения готовых файлов. |
